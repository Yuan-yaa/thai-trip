🇹🇭 泰国行

PWA 独立 App · 部署到 iPhone 桌面

🚀 推荐：GitHub Pages 一键部署

  1. 把 /workspace/ 下所有 8 个文件上传到 GitHub 仓库
  2. 进入仓库 Settings → Pages → Source 选 main 分支 → Save
  3. 等待 1-2 分钟，获得地址如：
    https://你的用户名.github.io/仓库名/

GitHub Pages 自动提供 HTTPS，完美支持 PWA

⚡ 最快：Vercel 拖拽部署

  1. 打开 vercel.com/new
  2. 把 /workspace/ 整个文件夹拖进去
  3. 自动部署完成，获得 https://xxx.vercel.app 地址

免费、自动 HTTPS、无需注册 GitHub 也能用

📲 部署后在 iPhone 上操作

  1. 用 Safari 打开部署后的网址
  2. 点击底部 分享按钮 ↑
  3. 选择 「添加到主屏幕」
  4. 确认名称「泰国行」→ 点击 「添加」

⚠️ 必须用 Safari，Chrome/微信内嵌浏览器不支持添加到桌面
